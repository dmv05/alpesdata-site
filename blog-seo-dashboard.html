Comment j'ai créé un Dashboard SEO automatisé pour suivre l'état de santé de mes sites

📅 25 juin 2026 ✍️ Didier Moranval-Vincent ⏱ 5 min de lecture
SEO Dashboard Automatisation Python Outils

Vous gérez plusieurs sites web et vous voulez savoir d'un coup d'œil s'ils sont en ligne, bien configurés, et optimisés pour le référencement ? C'est exactement ce que fait le nouveau dashboard SEO d'Alpesdata.

Dans cet article, je vous explique comment j'ai créé un tableau de bord SEO automatisé qui vérifie quotidiennement l'état de santé de tous mes sites. Un outil 100% maison, en Python, avec mise à jour automatique via cron.

🔎 C'est quoi le SEO ?

Le SEO (Search Engine Optimization, ou référencement naturel en français), c'est l'ensemble des techniques qui permettent à un site d'être bien positionné dans les résultats des moteurs de recherche comme Google, Bing ou DuckDuckGo.

Un bon SEO repose sur plusieurs piliers :

  • Technique : le site doit être rapide, accessible en HTTPS, sans erreurs
  • Contenu : des textes de qualité, des balises titres (title, H1), des meta descriptions
  • Popularité : des liens entrants (backlinks) depuis d'autres sites
  • Expérience utilisateur : navigation fluide, mobile-friendly, temps de charge

Sans suivi régulier, un site peut perdre des positions sans qu'on s'en rende compte : certificat SSL expiré, page 404, lenteur, balises manquantes… D'où l'idée d'un dashboard qui vérifie tout ça automatiquement.

💡 Le saviez-vous ?

47% des internautes quittent un site qui met plus de 2 secondes à charger. Un certificat SSL expiré peut faire chuter votre trafic de 90% du jour au lendemain. Le SEO, ce n'est pas optionnel — c'est vital pour votre visibilité en ligne.

⚙️ Comment ça marche ?

Le système est simple mais efficace :

1. Un script Python (check.py)

Le cœur du système est un script Python qui vérifie chaque site sur 4 aspects :

  • HTTP Status — le site répond-il correctement (code 200) ou y a-t-il une erreur ?
  • Temps de réponse — le serveur est-il rapide ? (mesuré en millisecondes)
  • Certificat SSL — le HTTPS est-il valide et combien de jours reste-t-il avant expiration ?
  • Balises SEO — le site a-t-il un title, une meta description, un H1, une URL canonique ?

2. Une génération HTML automatique

Le script produit un fichier index.html avec un tableau de bord visuel, clair et responsive. Chaque site reçoit un score SEO sur 5 étoiles.

3. Une mise à jour quotidienne (cron)

Une tâche planifiée (cron) lance le script automatiquement tous les matins à 9h00. Pas besoin d'y penser — le dashboard est frais chaque jour.

4. Un déploiement automatique

Le résultat est copié dans le dossier /seo/ du site, directement dans le conteneur Docker d'Alpesdata.com. Résultat : le dashboard est en ligne 30 secondes après chaque vérification.

💻 Les technologies utilisées

  • Python 3 — script principal (stdlib uniquement, pas de dépendances)
  • Docker / Nginx — hébergement du dashboard sur alpesdata.com
  • SSH + rclone — déploiement vers le VPS
  • Cron — planification quotidienne
  • Hostinger / VPS OVH — infrastructure serveur

📦 0 dépendance externe

Le script utilise uniquement la bibliothèque standard de Python : urllib pour les requêtes HTTP, ssl + socket pour les certificats, html pour l'échappement. Pas de package pip, pas de node_modules, pas de API payante. Ça tient dans un seul fichier de 450 lignes.

📈 Ce que le dashboard vérifie pour chaque site

Métrique Ce que ça vérifie Pourquoi c'est important
HTTP Status Code HTTP (200, 301, 404, 500…) Un site en 404 ou 500 est inaccessible
Temps de réponse Latence du serveur en ms Google pénalise les sites lents
SSL Validité et jours restants Certificat expiré = navigateur bloque le site
Balises SEO Title, meta description, H1, canonical Balises manquantes = mauvais référencement

🚀 Pourquoi c'est utile ?

Avant ce dashboard, je devais vérifier chaque site un par un, manuellement. C'était :

  • ❌ Chronophage (15-20 minutes chaque fois)
  • ❌ Pas de suivi dans le temps
  • ❌ Impossible de détecter une panne entre deux vérifications
  • ❌ Pas de vision d'ensemble

Maintenant avec le dashboard :

  • ✅ 22 sites vérifiés automatiquement, en continu (disponibilité, SSL, temps de réponse)
  • ✅ Un coup d'œil suffit pour voir l'état général
  • ✅ Alerte visuelle immédiate si un site a un problème
  • ✅ Rapport quotidien sans rien faire
  • ✅ Évolutif — j'ajoute un site en 30 secondes (une ligne de code)

Depuis la mise en place :
